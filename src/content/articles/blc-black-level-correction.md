黑电平校正（Black Level Correction）几乎是 ISP pipeline 里第一个动刀子的模块，但它也是最容易被误判的模块——很多"暗部偏色"的问题，根子并不在 BLC。

## 黑电平到底在补什么

CMOS 传感器的输出不是从 0 开始的。即使完全没有光子入射，像素也会输出一个正的偏置电压，来源有三块：

| 来源 | 特性 | 是否随增益变化 |
| --- | --- | --- |
| 像素复位噪声（kTC） | 逐帧随机 | 否 |
| 暗电流（Dark Current） | 随温度、曝光时间增长 | 否 |
| 模拟前端失调 | 固定偏置，随模拟增益放大 | **是** |

前两项构成"光学黑"（Optical Black），第三项才是 BLC 要补的主要对象。这也是为什么 BLC 的系数必须跟随模拟增益一起变，而不是一个固定常数。

## 光学黑区与有效像素区

传感器在有效像素阵列外围会留一圈被遮光的像素，称为 OB（Optical Black）区。ISP 的做法是：

1. 读取 OB 区若干行的统计值（通常按通道分别做均值或中位数）
2. 减去该值，得到近似零基线的数据
3. 用数字增益补偿因减法导致的动态范围损失

```c
/* 简化的 per-channel BLC 计算，R/Gr/Gb/B 四通道独立 */
for (ch = 0; ch < 4; ch++) {
    ob_mean[ch] = robust_mean(ob_pixels[ch], OB_ROWS, /*trim=*/0.1f);
    blc_offset[ch] = ob_mean[ch] - target_black;
    /* 数字增益补偿：减法吃掉的黑位要用 gain 拉回来 */
    blc_gain[ch] = (1 << bit_depth) / ((1 << bit_depth) - blc_offset[ch]);
}
```

其中 `target_black` 是人为设定的目标黑位（常见 64 @10bit 或 256 @12bit），保留一段"负噪声余量"，避免后续降噪把噪声削成 0 造成死黑。

> 这一步的关键取舍：`target_black` 设得高，暗部细节留得住但噪声大；设得低，画面干净但暗部会被"压平"。

## 三个常见误判

- **暗部偏绿 ≠ BLC 错**。Gr/Gb 通道的 OB 值本来就比 R/B 高，若四通道用了同一个 offset，绿色会整体抬高。先查 per-channel 是否独立。
- **高增益下黑位漂移**。这是模拟增益带来的失调被放大，需要在增益切换点重算 offset，而不是线性外推。
- **长曝光噪点**。那是暗电流，属于 DPC（坏点校正）与降噪的职责，BLC 只处理均值层面的偏置。

把这三条分开验证，能省掉大量在 BLC 参数上反复试错的时间。
